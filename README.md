# 🏏 IPL Tournament Performance Dashboard (2008–2025)

## 📊 Project Overview

This project presents an interactive **Power BI dashboard** analyzing the performance of teams and players in the Indian Premier League (IPL) from 2008 to 2025.

The dashboard provides insights into team dominance, player statistics, match outcomes, and season-wise trends to help users understand historical IPL performance.

---

## 🎯 Objectives

* Analyze team performance across seasons
* Identify top-performing players (batsmen & bowlers)
* Track win/loss trends and match results
* Compare seasonal performance
* Provide interactive visual insights for decision-making

---

## 📌 Key Features

* 📈 Team-wise performance analysis
* 🏆 Season winners and rankings
* 🧢 Top batsmen (runs, strike rate)
* 🎯 Top bowlers (wickets, economy)
* 📅 Year-wise trends (2008–2025)
* 🔍 Interactive filters (team, season, player)

---

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard creation and visualization
* **Excel / CSV** – Data preprocessing
* **DAX** – Calculations and measures

---

## 📂 Dataset

The dataset includes:

* Match details (teams, venue, results)
* Player statistics
* Season-wise data from 2008 to 2025

> Note: Dataset is either publicly available or modified for analysis purposes.
